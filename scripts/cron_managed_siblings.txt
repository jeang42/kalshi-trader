# Managed-exits sibling profiles — cron entries
# ────────────────────────────────────────────────────────
# HISTORY: These profiles originally ran full exit management (TP/SL/
# vol-aware trail/time-stop). After analyzing results (2026-05-26):
#   - 4,322 exits on agentic_llm_managed: 0% win rate, -$186K
#   - 1,210 exits on agentic_managed: 0.2% win rate, -$13K
#   - Every managed profile underperformed its unmanaged sibling
#
# ROOT CAUSE: prediction markets resolve to $0/$1. Stop-losses lock in
# losses on positions that would have come back at resolution. The LLM
# forecasts are genuinely good (gemma3 Brier 0.095) but the exit
# management was destroying the edge by selling on noise.
#
# DECISION: exit management DISABLED on all non-baseball profiles.
# These now mirror the unmanaged profiles (hold to resolution) but
# keep the --max-positions-per-event cap. The "managed" name is
# retained for profile continuity. Exit flags are preserved in
# comments below for reference if we ever revisit.
#
# EXCEPTION: agentic_baseball_managed keeps SL/time-stop because
# baseball games resolve within hours and the in-game swing thesis
# requires position management. This is a different strategy class.
#
# Original exit flags (all non-baseball):
#   --take-profit-pct 0.25 --tp-to-trail-stop-pct 0.05
#   --stop-loss-pct 0.25 --trail-stop-atr-mult 2.0
#   --trail-vol-window-hours 24-48 --time-stop-days 7-30
